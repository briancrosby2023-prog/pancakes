# OP-X-050 Context Architecture

OP-X-043A competitive evidence record -> canonical card resolution -> existing Pancake/discovery link -> realized build -> deployment -> role -> scheme/assignment -> behavior/animation evidence -> physical geometry -> ability/AP context -> contextual evaluation.

OP-X-043A remains the only ingestion, provenance, deduplication, card-resolution, source-family, ability-semantics, and usage/testimony system. OP-X-050 adds optional contextual fields to that record and consumes them; it does not create a second evidence registry.

The contextual layer is explanatory and non-numeric. It MUST NOT mutate frozen score, rank, percentile, OP-X-028 methodology, market semantics, or purchase gates. Canonical position and deployment position are independent. UNKNOWN is a first-class state and creates neither bonus nor penalty.
