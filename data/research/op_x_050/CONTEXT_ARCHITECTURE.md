# OP-X-050 Context Architecture

Canonical card -> realized build -> frozen position score -> deployment -> role -> scheme/assignment -> behavior/animation evidence -> physical geometry -> ability/AP context -> contextual evaluation.

The contextual layer is explanatory and non-numeric. It MUST NOT mutate frozen score, rank, percentile, OP-X-028 methodology, market semantics, or purchase gates.

Canonical position and deployment position are independent. A TE used through Gadget at HB remains canonically TE. UNKNOWN is a first-class state and creates neither bonus nor penalty.

Realized builds distinguish THEORETICAL from OBSERVED. Ability availability, equipped state, and competitive value are separate facts.
