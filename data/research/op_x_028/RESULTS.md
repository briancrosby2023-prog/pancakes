## Population geometry

## Value index

The index is a confidence-adjusted weighted composite: score gain 25%, within-position
percentile gain 25%, normalized rank gain 15%, local scarcity 15%, and roster need 20%.
One-at-a-time component ablations are persisted. No component alone can contribute more
than 25 unadjusted points. OP-X-024 same-OVR slack is retained only as hypothesis context;
production model weights determine the attribute-contribution profile.

## Limitations

The framework measures relative football and roster value. It does not estimate market
clearing price, gameplay wins, or EA attribute coefficients. Absolute coin boundaries are
not scientifically supported, so the full hypothetical cost curves are exposed instead.
The broader test suite cannot collect because the existing E.15 test imports the absent
optional `requests` package; the OP-X-028 and relevant regression suites pass.
